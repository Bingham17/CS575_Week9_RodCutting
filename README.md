# CS575_Week9_RodCutting

Rod Cutting
A fairly simple dynamic programming problem.  You'll be given the length of the rod, and then the number of length/price pairs.  After that, there's each potential pair.  For example, if you have a rod of length 14, and you can sell 1-unit length for $3 and 3-unit length for $10, determine the maximum value you can get for the rod (and print that out).  The input file will look like this:

14 2
1 3
3 10
